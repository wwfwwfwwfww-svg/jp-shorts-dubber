# 일본어 영화쇼츠 더빙 — 자동 파이프라인

영상 업로드 한 번으로 **① 자막추출 → ② 일본어 → ③ TTS/QA → ④ 메타데이터** 까지
프로그램 안에서 끝나는 로컬 웹 도구. 각 단계 사이에 사람 확인 게이트가 있고,
**비용이 드는 단계(Vision·번역·TTS)는 버튼을 눌러야만** 진행됩니다.

## 시작하기
1. **키 2개** (`.env`): `ANTHROPIC_API_KEY`(1·2·4단계, vision 모델) + `ELEVENLABS_API_KEY`(3단계).
2. venv: `py -3.12 -m venv .venv` → 활성화 → `pip install -r requirements.txt`
3. `copy .env.example .env` 후 키 입력.
4. **`start.bat` 더블클릭** → 브라우저 자동 오픈. (콘솔 창은 닫지 마세요 = 서버)

## 파이프라인
- **입력**: 영상 업로드(또는 URL). 백업 탭: 이미 만든 일본어 대본(`시작|종료|일본어`) → 바로 ③.
- **① 자막추출 (Claude Vision)**: 0.5초 프레임 → 하단 자막 크롭 → 타임스탬프 라벨 콘택트시트 →
  Claude Vision이 화면 글자를 직접 읽어 구간/타이밍/타입(흰=나레이션/색=대사) 산출. **한국어·영어 모두** OK.
- **② 일본어 (Claude)**: 스토리 전체를 읽고 **줄거리 레벨로 재구성**(직역 아님). 글자수 예산으로
  **영상 전체 단일 배속**(1.15~1.2x) 산출, Python 실측 글자수로 검증 루프. 일본어 + 한국어 역번역 병기.
- **③ TTS/QA (ElevenLabs)**: 단일 배속으로 생성 → **순차 연결**(겹침 없음) → 자동 음량정규화(-1dB) →
  자동 QA(발화수/클리핑/피크/겹침) 체크리스트. 구간별 재생성 지원.
- **④ 메타데이터 (Claude)**: 제목 후보·썸네일 2줄·설명·태그(JP+KR) + 최종 SRT(JP·KR, 실제 오디오 길이 기준).

## 다운로드
MP3 / WAV / SRT(JP) / SRT(KR) / ZIP.

## 설계 메모
- 오디오는 **순차 연결**(원본 타임스탬프 고정 안 함). ②의 단일 배속+글자수 예산이 총 길이를
  원본과 비슷하게 맞춰 누적 오차를 최소화. 이 장르(줄거리 보이스오버)에 적합.
- OCR(Tesseract/EasyOCR) 미사용 — 전부 Claude Vision.

## 키 없을 때
`.env`에 키가 없으면 해당 단계 버튼 클릭 시 어느 키가 필요한지 에러로 표시됩니다.
화면 상단에 키 감지 상태도 표시됩니다.
