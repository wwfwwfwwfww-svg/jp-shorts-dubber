# 일본어 영화쇼츠 더빙 — 자동 파이프라인

영상 업로드 한 번으로 **① 자막추출 → ② 일본어 → ③ TTS/QA → ④ 메타데이터** 까지
프로그램 안에서 끝나는 로컬 웹 도구. 각 단계 사이에 사람 확인 게이트가 있고,
**비용이 드는 단계(Vision·번역·TTS)는 버튼을 눌러야만** 진행됩니다.

## 시작하기 (쉬운 방법)
> 이 프로그램은 **웹 UI**입니다. 실행하면 검은 콘솔 창(=서버)이 뜨고, 브라우저가
> `http://localhost:8000` 으로 자동으로 열립니다. 사용하는 동안 콘솔 창은 닫지 마세요.

1. **`바탕화면_바로가기_만들기.bat` 더블클릭** (최초 1회)
   - 파이썬 가상환경 생성 + 패키지 설치 + `.env` 준비 + **바탕화면 바로가기 생성**까지 자동.
   - 이어서 메모장으로 열리는 `.env`에 API 키를 채워 저장하세요.
2. 이후에는 **바탕화면의 "쇼츠 스튜디오 (더빙+소재찾기)" 아이콘 더블클릭**이면 실행 끝.
   - (바로가기 없이 폴더 안 **`start.bat`을 더블클릭**해도 동일하게 실행됩니다. 최초 실행 시 자동 설치.)

### API 키 (`.env`)
- `ANTHROPIC_API_KEY` — 더빙 1·2·4단계(Vision·일본어·메타) + 소재 찾기의 AI 분류/미진출 판별.
- `ELEVENLABS_API_KEY` — 더빙 3단계(TTS).
- `YOUTUBE_API_KEY` — **소재 찾기** 탭의 검색. 앱의 소재찾기 탭 → ⚙설정 화면에서 입력·검사할 수도 있습니다.
- `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` — (선택) 알림. 없으면 알림만 꺼지고 나머지는 정상.

### 파이썬이 없다면
[python.org/downloads](https://www.python.org/downloads/) 에서 **Python 3.12** 설치 시
"Add Python to PATH"를 꼭 체크하세요. 그 후 위 1번을 다시 실행하면 됩니다.

## 업데이트 (새 버전 받기) — ⚠ 폴더 하나만 쓰세요
- 업데이트는 **`업데이트.bat` 더블클릭** 한 번이면 됩니다. 최신 코드만 덮어쓰고
  **찾아둔 영상(`data\`)·API 키(`.env`)·설치(`.venv\`)는 그대로 유지**합니다.
- **ZIP를 매번 새 폴더로 받지 마세요.** 새 폴더는 `data\`가 비어 있어(저장소에 포함 안 됨)
  그동안 찾은 영상이 안 보입니다. **폴더 하나를 정해 그 안에서만** 업데이트하세요.
- 수집한 영상·설정은 프로젝트 폴더의 **`data\finder.db`** 등에 저장됩니다(이 폴더를 지우면 초기화).

## 탭
- **🎬 일본어 더빙** — 아래 파이프라인(기존 그대로).
- **🔎 소재 찾기** — 해외 인기/급등 쇼츠를 검색·수집해 배수·미진출 여부로 소재 발굴 → 「작업하기」로 더빙 준비.
- **🎬 제작(자막교체)** — 음악+영어자막 영상의 자막만 일본어로 교체(원본 소리 유지). 전부 로컬.

## 파이프라인
- **입력**: 영상 업로드(또는 URL). 백업 탭: 이미 만든 일본어 대본(`시작|종료|일본어`) → 바로 ③.
- **① 자막추출 (Claude Vision)**: 0.5초 프레임 → 하단 자막 크롭 → 타임스탬프 라벨 콘택트시트 →
  Claude Vision이 화면 글자를 직접 읽어 구간/타이밍/타입(흰=나레이션/색=대사) 산출. **한국어·영어 모두** OK.
- **② 일본어 (Claude)**: 스토리 전체를 읽고 **줄거리 레벨로 재구성**(직역 아님). 글자수 예산으로
  **영상 전체 단일 배속**(1.15~1.2x) 산출, Python 실측 글자수로 검증 루프. 일본어 + 한국어 역번역 병기.
- **③ TTS/QA (ElevenLabs)**: 단일 배속으로 생성 → **순차 연결**(겹침 없음) → 자동 음량정규화(-1dB) →
  자동 QA(발화수/클리핑/피크/겹침) 체크리스트. 구간별 재생성 지원.
- **④ 메타데이터 (Claude)**: 제목 후보·썸네일 2줄·설명·태그(JP+KR) + 최종 SRT(JP·KR, 실제 오디오 길이 기준).

## 다운로드
MP3 / WAV / SRT(JP) / SRT(KR) / ZIP.

## 설계 메모
- 오디오는 **순차 연결**(원본 타임스탬프 고정 안 함). ②의 단일 배속+글자수 예산이 총 길이를
  원본과 비슷하게 맞춰 누적 오차를 최소화. 이 장르(줄거리 보이스오버)에 적합.
- OCR(Tesseract/EasyOCR) 미사용 — 전부 Claude Vision.

## 키 없을 때
`.env`에 키가 없으면 해당 단계 버튼 클릭 시 어느 키가 필요한지 에러로 표시됩니다.
화면 상단에 키 감지 상태도 표시됩니다.
